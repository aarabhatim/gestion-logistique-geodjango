# Mockups nouveau design DeliverMap

Ce dossier contient trois simulations visuelles du nouveau design, sans modification du code du projet.

- `client-dashboard-redesign.svg` : experience client moderne avec commande rapide, suivi live, boutiques et promotions.
- `admin-operations-redesign.svg` : centre de controle admin avec KPI, carte temps reel, heatmap et alertes.
- `transporteur-driving-redesign.svg` : mode conduite transporteur avec itineraire, ETA et actions rapides.

Si les PNG sont generes, ils auront les memes noms avec l'extension `.png`.
